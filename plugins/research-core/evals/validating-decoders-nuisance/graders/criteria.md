The response points out that on correct trials the choice is fully determined by the trial type (lick ≡ the rewarded condition), so the decoder may read the stimulus or trial type rather than the choice, and that licks or movements in the delay are a second nuisance. It asks for decoding on all trials (including errors) or for nuisance-matched trials (the same trial type with different choices), and a null built by the same pipeline.
