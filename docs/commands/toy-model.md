# /toy-model

## What it does

A throwaway minimal simulation that answers whether a mechanism works at all, before a sweep is designed: one script, one figure, one short card marked toy.

## When to reach for it

An idea's premise is untested and a sweep would be expensive to waste.

## Common questions

**Does a working toy show the trained nets use the mechanism?**
No, and its card says so.

**Where does the code go?**
Into scratch, committed once, then deleted or moved: the answer is kept, not the code.

## It's working if

The killing answer was written before the code, and the next plan changed or held because of it.
