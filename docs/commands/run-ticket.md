# /run-ticket

## What it does

One ticket end to end in one session: fetch and claim it, write the pre-run card, get your OK on the parameters, run it with the skills of its kind, audit, append the verdict card, close the ticket with the card, refuted or not.

## When to reach for it

Starting a session on a spec: take the first ticket of the frontier, or the one you name.

## Common questions

**What if the sweep takes hours?**
The session stops after launching, with the ticket still claimed; /run-ticket on the same ticket later resumes at the audit.

**Can it add an arm?**
No: anything the ticket does not name is asked.

## It's working if

The verdict card names the ticket, the ticket's closing comment links the card, and the next frontier is stated.
