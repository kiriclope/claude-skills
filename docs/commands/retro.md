# /retro

## What it does

Looks back over a session and proposes changes to the environment (skills, hooks, scripts, CLAUDE.md, memory), never to the research code.

## When to reach for it

A session went sideways, or a mistake should never happen again.

## Common questions

**When to run it?**
Before the session is cleared or compacted; afterwards, from its transcript.

## It's working if

Mechanical mistakes became checks or hooks; judgment calls became rules with their why.
