# /ask

## What it does

Routes you to the skill or flow that fits your situation. It reads the skill it recommends before describing it, and answers with one flow and its first command.

## When to reach for it

You don't remember which skill fits, or you're about to start something big and want the right flow.

## Common questions

**Does it replace the profile's skill table?**
It holds the same map as a flow. The profile keeps its short table, because that loads in every session; `/ask` is for when you want to be routed.

## It's working if

It names one flow and its first command, and the skill it names really does what it said.
