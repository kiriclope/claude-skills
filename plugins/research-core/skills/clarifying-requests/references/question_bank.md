# Question bank

Dimensions of a task, the question that pins each one down, and examples. Pick the two to four
dimensions that are actually open; ask problem-level ones (top of the table) before detail-level ones.

| dimension | the question it answers | example question (options) |
|---|---|---|
| goal | why is this wanted, what decision or claim does it serve? | "Is this to decide the next sweep, or to make a paper panel?" |
| interpretation | which of the plausible readings is meant? | "'Better flows': more accurate field, or more legible figure?" |
| success | how will we know it is done or right? | "Done when every seed is scored, or when one clean example exists?" |
| deliverable | what comes back, in what form, where does it go? | "A figure in the gallery, a table in chat, or a paragraph for the draft?" |
| scope | which data, runs, files, panels — and what is out? | "All 8 seeds or the 4 learners? Expert stage only?" |
| constraints | time, compute, what must not change, style | "Can it launch new runs, or only re-analyze existing ones?" |
| audience | who reads or uses it? | "For you, for colleagues, or for reviewers?" |
| prior | what is known, tried, ruled out? | "Did the noise-averaged field already rule this out?" |
| trade-off | which matters more when they conflict? | "Fast and approximate today, or rigorous over the week?" |
| detail | the concrete specifics once the above are fixed | "Which color is the cat?" |

## Worked examples

**"Draw a cat."** (detail-level example)
Mirror: "A cat drawing — for what?" → goal (illustration for a talk / a test of the plotting
style / fun), then detail: style (line drawing, realistic, cartoon), color, size, file format.

**"Make figure 5 better."**
Look first: which file builds figure 5, what the last review said. Mirror: "Better how — the
reviewer-facing claim, or how it reads at print size?" Ask: goal (claim vs legibility), scope
(which panels), constraints (keep the data and layout, or free to redesign?), done-when (passes
check_figure and the caption reads in one pass?).

**"Look at the flows of the new sweep."**
Look first: which sweep is newest, whether verdicts exist. Mirror: "Do you want the score (are
the wells down?) or an explanation (why this arm differs)?" Ask: question (score vs mechanism),
scope (which arms/seeds/stage), deliverable (verdict table, figures in the gallery, both).

**"Is the result solid?"**
Look first: which result was last discussed. Mirror: "Solid enough to put in the paper, or to
build the next sweep on?" Ask: which claim exactly, the criterion it must meet, which
controls are in scope — then hand the spec to thinking-critically.
